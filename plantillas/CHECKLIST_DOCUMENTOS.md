# Checklist de documentos

Copia este archivo y ve marcando. El objetivo es que **ninguna aplicación se frene por buscar un papel**.

Ten todo en una sola carpeta, en PDF, con nombres consistentes: `Apellido_Tipo_Año.pdf`.

```
Documentos/
├── 01_CV/
├── 02_Identidad/
├── 03_Educacion/
├── 04_Laboral/
├── 05_Sector/
└── 06_Media/
```

Estados sugeridos: **Tiene** · **Falta** · **Verificar** · **Solicitado** · **N/A**

## Antes de cada envío — 6 puntos

1. ¿El CV correcto para ese perfil?
2. ¿Es **PDF**? Nunca .docx
3. ¿Nombre de archivo correcto?
4. ¿Desde el correo profesional?
5. ¿Se declararon las brechas reales?
6. ¿Se registró la fecha? Seguimiento a los **10 días hábiles**
